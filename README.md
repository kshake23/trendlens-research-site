# TrendLens Research public landing page

This folder is intentionally separate from the private Merch Ops dashboard. It contains only static public-facing HTML and CSS; no API keys, dashboard data, credentials, personal information, or private research records are included.

## Publish with GitHub Pages

Create a separate public repository, for example `trendlens-research-site`, then copy the contents of this folder to the repository root and enable **Settings → Pages → Deploy from branch → main → /(root)**. The expected URL will be `https://<github-username>.github.io/trendlens-research-site/`.

The exact URL cannot be confirmed until a writable GitHub account/repository is connected and Pages finishes its first deployment.
